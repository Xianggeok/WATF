**Why are they fighting?**

A Minecraft Fabric mod that adds two magical staffs to make mobs fight each other!

> ⚠️ **Note: This mod was created with AI assistance**

## ✨ Features

### 🗡️ Duel Staff
- Select two mobs to make them fight in a **1v1 duel**
- Works on non-passive mobs
- Same-species mobs can also fight each other

### ⚔️ Team Battle Staff
- Select two different species to start a **team battle**
- Automatically searches for all nearby same-species mobs to join
- Supports large-scale species warfare

- ✅ Chinese & English language support
- ✅ Item tooltip descriptions

## 🎮 How to Use

1. **Duel Staff**: Right-click the first mob, then right-click the second mob to start a duel!
2. **Team Battle Staff**: Right-click any mob of the first species, then right-click any mob of the second species — all nearby same-species mobs will join the battle!

## 📦 Installation

1. Install [Fabric Loader](https://fabricmc.net/) (>= 0.19.2)
2. Install [Fabric API](https://modrinth.com/mod/fabric-api)
3. Download the mod jar from the [Release page](https://github.com/Xianggeok/WATF/releases)
4. Put the jar file into your `mods` folder

## 🔨 Building from Source

```bash
# Clone the repository
git clone https://github.com/Xianggeok/WATF.git
cd WATF

# Switch to target version branch
git checkout 1.21.4  # or other version branch

# Build
./gradlew build

# Output located at
# build/libs/watf-1.1.0.jar
```
