# [WATF] Why Are They Fighting?

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Minecraft Version](https://img.shields.io/badge/Minecraft-26.1-green)]()
[![Fabric](https://img.shields.io/badge/Loader-Fabric-5C469C?logo=fabric)](https://fabricmc.net/)

**他们为什么要打架?**

一个 Minecraft Fabric 模组，添加了两个神奇的法杖，可以让生物之间互相战斗！

> ⚠️ **声明：本模组由 AI 辅助制作**

## ✨ 功能

### 🗡️ 决斗法杖
- 选中两个生物，让它们进行 **1v1 决斗**
- 对非被动生物有效
- 同种族生物也能互打

### ⚔️ 团战法杖
- 选中两个不同的物种，让它们进行 **群体团战**
- 自动搜索范围内所有同种生物参战
- 支持大规模物种对战

## 📥 下载

前往 [Release](https://github.com/Xianggeok/WATF/releases/latest) 或 [Modrinth](https://modrinth.com/project/XAgkS2Pl) 下载最新版本的 jar 文件。

## 🔧 合成配方

### 决斗法杖
```
烈焰粉 | 下界之星 | 紫水晶碎片
  空   |   金锭   |    空
  空   |   木棍   |    空
```

### 团战法杖
```
烈焰粉 | 下界之星 | 紫水晶碎片
  空   |   钻石   |    空
  空   |   木棍   |    空
```

## 📋 特性

- ✅ 支持 Goal AI 生物（僵尸、骷髅等）
- ✅ 支持 Brain AI 生物（猪灵、猪灵蛮兵等）
- ✅ 同种族生物互打
- ✅ 中英文支持
- ✅ 物品栏描述提示

## 🎮 使用方法

1. **决斗法杖**：右键选中第一个生物，再右键选中第二个生物，它们就会开始决斗！
2. **团战法杖**：右键选中第一个物种的任意生物，再右键选中第二个物种的任意生物，附近所有同种生物都会参战！

## 📦 安装

1. 安装 [Fabric Loader](https://fabricmc.net/) (>= 0.19.2)
2. 安装 [Fabric API](https://modrinth.com/mod/fabric-api)
3. 从 [Release 页面](https://github.com/Xianggeok/WATF/releases) 下载模组 jar 文件
4. 将 jar 文件放入 `mods` 文件夹

## 🔨 构建

如果你想从源码构建：

```bash
# 克隆仓库
git clone https://github.com/Xianggeok/WATF.git
cd WATF

# 构建
./gradlew build

# 构建产物位于
# build/libs/watf-1.0.0.jar
```
